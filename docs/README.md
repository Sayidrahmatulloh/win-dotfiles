# Hujjatlar xaritasi

Loyihani tushunish uchun quyidagi tartibda o'qing:

1. [Kod xaritasi](code-guide.md) — kirish skriptlari va kerakli faylni topish.
2. [Arxitektura](architecture.md) — papkalar mas'uliyati, ma'lumot va bajarilish oqimi.
3. [O'zgartirish qoidalari](../CONTRIBUTING.md) — yangi kodning joyi va tekshiruvlar.
