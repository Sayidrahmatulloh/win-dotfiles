# Dastur konfiguratsiyalari

Bu papkada dasturlar o'z formatida o'qiydigan sozlamalar saqlanadi:

| Papka | Mazmuni |
| --- | --- |
| `nvim/` | Native Neovim va VS Code Neovim muhitlari |
| `powershell/` | Profil modullari, prompt va PowerShell module ro'yxati |
| `terminal/` | Windows Terminal profillari va ko'rinishi |
| `git/` | Umumiy Git sozlamalari |
| `glzr/` | GlazeWM va Zebar startup sozlamalari |
| `vscode/` | VS Code ko'rinish sozlamalari |
| `qutebrowser/` | Dark green brauzer interfeysi, sessiya va qidiruvlar |

Qayerga ulanishi `../setup.json`da, ulash amali esa
`../scripts/install/links.ps1`da belgilanadi. `symlinks.ps1` eski buyruqlar uchun
compatibility kirish nuqtasi bo'lib qoladi. Profil va startup adapterlari tegishli
dastur papkasida turadi; umumiy o'rnatish amallarini bu yerga qo'shmang.

[Neovim qo'llanmasi](nvim/README.md).
